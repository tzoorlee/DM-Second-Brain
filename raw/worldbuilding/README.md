# Worldbuilding — Design Material

> Drop your plans here: draft cities, factions, NPCs, plot hooks, lore — things that
> haven't happened in play yet.
>
> The agent processes it with the DESIGN INGEST operation: it creates wiki entities
> with `canon_status: prepared`. When the PCs touch them in play, they become `established`.
>
> **Before the first session**, write freely, in any files: the agent structures it.
> **After the first session**, add each new batch as a new dated file,
> `YYYY-MM-DD-<slug>.md` (e.g. `2027-03-05-the-frozen-north.md`), so the agent ingests
> only what is new. Design that contradicts what was already played is flagged, not written.
>
> What happened off-screen between sessions is not design: put it in `raw/interludes/`.
