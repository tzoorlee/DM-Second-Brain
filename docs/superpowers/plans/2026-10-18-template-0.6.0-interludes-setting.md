# Template 0.6.0 — Interludes and Setting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Template 0.6.0: `raw/interludes/` and `raw/setting/`, world-bible `## Campaign` and `## Setting` sections, and the `CLAUDE.md` rules the World Studio relies on (part 1 of the World Studio spec).

**Architecture:** Documentation-only release of the template repository. Vault format stays 1. The world-bible's `## ` headings become a contract read by the companion app, like `## Secrets (DM only)`.

**Tech Stack:** Markdown, YAML frontmatter, git, `gh`.

**Spec:** `/home/fabioschenone/sviluppo/DM-Second-Brain-app/docs/superpowers/specs/2026-10-18-world-studio-design.md` (section A; on the app repo's `feat/world-studio` branch)

## Global Constraints

- `dm-second-brain.json` unchanged (`{ "vaultFormat": 1 }`).
- World-bible headings are fixed English markers: `## Campaign`, `## Setting`, `## Tone and Atmosphere`, `## Lore Pillars (immutable truths)`, `## Naming Conventions`, `## Basic Geography`, `## Cosmology`, `## Things that do NOT exist in this world`, `## Style notes for the agent`.
- Interlude files: `raw/interludes/YYYY-MM-DD-<slug>.md` (real date), frontmatter `date_in_world: "YYYY-Month-DD"`, `after_session: session-NN`.
- `.dm-second-brain/` is the companion app's working folder: the agent never reads it as a source and never edits it.
- No new world content in the example (rule 2): only fields the example already states.
- Version 0.6.0 everywhere the current version appears; `CLAUDE.md` links `TEMPLATES.md` at `v0.6.0`.

## Review Focus

- An agent reading the new `CLAUDE.md` must not translate the world-bible headings when it writes the wiki in another language (they are in `raw/`, which it never edits, but the DM might ask it to draft one). The fixed-markers paragraph in §3 must name them.
- An interlude that says the PCs witnessed the event must not end up `pg_known: false`: the rule must say "unless the interlude says the PCs know".
- A design ingest on an old campaign (no dated files, no sessions) must work exactly as before.
- `raw/setting/` holding copyrighted excerpts: the README must say it stays in the DM's private vault and must not be published.
